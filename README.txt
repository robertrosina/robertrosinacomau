ROBERT ROSINA — UNIFIED WEBSITE

This package joins the two bodies of work under one website:

1. /author/ — books, Wyrdcasters and Owl Fred
2. /the-modern-bard/ — live performance, repertoire, gallery and bookings

The root index is a shared gateway presenting both limbs equally. Cross-links appear in both sections. Upload the contents of this folder to the web root of robertrosina.com.au.

Booking/contact email: robertrosina@outlook.com.au


DOMAIN AND NAVIGATION
---------------------
The complete site belongs at https://robertrosina.com.au/.
Upload the CONTENTS of this folder to the domain web root. Navigation links point directly to each section's index.html so the server cannot show a directory listing in place of a page. The included .htaccess also sets index.html as the directory index and disables folder browsing on Apache-compatible hosting.
